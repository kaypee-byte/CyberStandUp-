## Question 1: What did you complete or learn this week? Provide evidence.

### Theory — Network Hacking Fundamentals

This week I focused on the fundamentals of network hacking. I learned that network hacking is the process of finding and using weak spots in a computer network to get inside without permission, steal data, or stop the system from working. I covered how this process unfolds in three stages:

•	Reconnaissance / Scouting — the information-gathering stage, including scanning for open ports and checking which services are active on a target.

•	Exploitation (Breaking In) — using tools such as Metasploit or custom scripts to take advantage of a discovered weakness.

•	Action (Doing the Damage) — what a hacker does once inside, e.g. stealing private files, installing malware, or knocking a network offline with a Denial-of-Service (DoS) attack.

I also learned about the different types of malicious software (malware, spyware, ransomware), the different types of hackers (black hat, white hat, and grey hat), and networking concepts including MAC addresses, wireless adapters, deauthentication attacks, and packet sniffing with tools like Airodump-ng.

### Practical — Changing a MAC Address on Kali Linux

For my hands-on practical this week, I changed the MAC address on my Kali Linux machine to disguise my device's identity on a network. I used the following steps:

•	Listed my network interfaces using ifconfig to identify the correct interface (e.g. eth0 or wlan0).

•	Brought the interface down before making changes: sudo ifconfig eth0 down

•	Changed the MAC address using: sudo ifconfig eth0 hw ether XX:XX:XX:XX:XX:XX

•	Brought the interface back up: sudo ifconfig eth0 up

This demonstrated the concept of anonymity in network hacking — changing the MAC address hides the real identity of a device on a network.
